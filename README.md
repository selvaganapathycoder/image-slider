# Image Slider

A responsive and lightweight image slider built using HTML, CSS, and JavaScript. This slider cycles through images automatically and allows manual navigation through previous/next buttons.

## 🔗 Live Demo

[Click here to view the live demo](https://selvaganapathycoder.github.io/image-slider/)


## 🚀 Features

- Auto-sliding images
- Manual next/previous controls
- Smooth transition effects
- Fully responsive layout
- Easy to customize

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
